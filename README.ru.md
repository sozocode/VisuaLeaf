## Что такое VisuaLeaf?

VisuaLeaf — это визуальное **рабочее пространство для баз данных**, созданное для разработчиков, DBA и команд, работающих с данными. Проект начинался как GUI для MongoDB, а теперь ничуть не хуже работает как **SQL-клиент**: подключайтесь к MongoDB, PostgreSQL, MySQL, MariaDB, SQL Server, Oracle, SQLite, ClickHouse, Redis и другим базам и используйте один и тот же визуальный подход в каждой из них.

Собирайте запрос мышью, стройте ER-диаграмму по внешним ключам или по тому, что реально хранится в MongoDB, редактируйте таблицы и документы прямо на месте, профилируйте медленные запросы, переносите данные между базами, создавайте дашборды и поручайте ИИ набрасывать запросы по вашей реальной схеме. Всё работает локально и подключается напрямую к вашим базам данных.

### Почему команды выбирают VisuaLeaf

- **Одно приложение для MongoDB и SQL**: 36 баз данных — документные, реляционные, key-value и аналитические — в одном рабочем пространстве.
- **Все SQL-функции бесплатны** в Community Edition.
- **Визуальные конструкторы запросов для обоих миров**: SQL с JOIN, подсказанными по внешним ключам, и фильтры MongoDB с группами AND/OR.
- **ER-диаграммы и визуализация схемы**: строятся по внешним ключам SQL или выводятся из коллекций MongoDB, а готовый дизайн можно материализовать в настоящие таблицы или коллекции.
- **SQL-редактор и оболочка MongoDB**: подсветка синтаксиса, автодополнение, история и результаты в виде таблицы, дерева или JSON.
- **Конструктор конвейеров агрегации с drag-and-drop** и предпросмотром на каждом этапе.
- **ИИ-ассистент**, который пишет запросы, агрегации и графики по описанию обычным языком и объясняет планы запросов.
- **Встроенный MCP-сервер**: подключайте Claude, Cursor и другие ИИ-инструменты к своим базам данных.
- **Быстро на реальных данных**: 50 000 документов открываются за секунды, а документы на пределе в 16 МБ MongoDB обрабатываются без проблем.
- **Ваши данные остаются у вас**: прямые подключения, без прокси, без телеметрии по вашим запросам.

## Безопасность и приватность

**Ваши данные остаются у вас.** VisuaLeaf подключается напрямую с вашей машины к вашим базам данных. Мы никогда не видим, не храним и не проксируем ваши данные.

- **Прямые подключения**: localhost, MongoDB Atlas, управляемые облачные базы или любой собственный сервер
- **SSH-туннели и SSL**: защищённые подключения через bastion-хосты и к облачным инстансам
- **Работа офлайн**: после активации приложение полностью работает без интернета
- **Локальное хранение учётных данных**: данные подключений хранятся в зашифрованном виде на вашей машине
- **Без телеметрии запросов**: мы не отслеживаем, что вы запрашиваете и к каким данным обращаетесь
