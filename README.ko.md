## VisuaLeaf란?

VisuaLeaf는 개발자, DBA, 데이터 팀을 위한 비주얼 **데이터베이스 워크스페이스**입니다. MongoDB GUI로 시작했지만 이제는 **SQL 클라이언트**로도 똑같이 잘 동작합니다. MongoDB, PostgreSQL, MySQL, MariaDB, SQL Server, Oracle, SQLite, ClickHouse, Redis 등에 연결하고, 모든 데이터베이스에서 동일한 비주얼 워크플로를 사용할 수 있습니다.

클릭만으로 쿼리를 만들고, 외래 키나 MongoDB에 실제로 저장된 데이터로부터 ER 다이어그램을 그리고, 테이블과 도큐먼트를 인라인으로 편집하고, 느린 쿼리를 프로파일링하고, 데이터베이스 간에 데이터를 옮기고, 대시보드를 만들고, AI에게 실제 스키마를 바탕으로 쿼리 초안을 맡길 수 있습니다. 모든 것이 로컬에서 실행되며 데이터베이스에 직접 연결됩니다.

### 팀이 VisuaLeaf를 선택하는 이유

- **MongoDB와 SQL을 하나의 앱에서**: 도큐먼트, 관계형, 키-값, 분석용까지 36개 데이터베이스를 하나의 워크스페이스에서 다룹니다.
- **모든 SQL 기능이 무료**: Community Edition(커뮤니티 에디션)에서 제한 없이 사용할 수 있습니다.
- **양쪽 세계를 위한 비주얼 쿼리 빌더**: SQL은 외래 키 기반 JOIN 추천, MongoDB는 AND/OR 그룹 필터를 지원합니다.
- **ER 다이어그램과 스키마 시각화**: SQL 외래 키에서 생성하거나 MongoDB 컬렉션에서 추론하며, 설계한 내용을 실제 테이블이나 컬렉션으로 구체화(Materialize)할 수 있습니다.
- **SQL 편집기와 MongoDB 셸**: 구문 강조, 자동 완성, 기록을 지원하고 결과를 그리드, 트리, JSON으로 확인할 수 있습니다.
- **드래그 앤 드롭 집계 파이프라인 디자이너**: 모든 스테이지에서 미리보기를 제공합니다.
- **AI 어시스턴트**: 일상 언어로 쿼리, 집계, 차트를 작성하고 쿼리 플랜을 설명해 줍니다.
- **내장 MCP 서버**: Claude, Cursor 등 AI 도구를 데이터베이스에 연결할 수 있습니다.
- **실제 데이터에서도 빠르게**: 도큐먼트 50,000개를 몇 초 만에 열고, MongoDB의 16 MB 한도에 달하는 도큐먼트도 무리 없이 처리합니다.
- **데이터는 로컬에만**: 직접 연결, 프록시 없음, 쿼리에 대한 텔레메트리 없음.

VisuaLeaf의 출발점이 된 도구들로, MongoDB, Atlas, Cosmos DB, DocumentDB에서 사용할 수 있습니다.

### 컬렉션 탐색
도큐먼트를 세 가지 방식으로 탐색합니다. 중첩 데이터에는 트리 보기, 빠른 훑어보기에는 테이블 보기, 원시 타입을 그대로 확인하려면 BSON 보기를 사용하세요. 필터링, 정렬, 인라인 편집은 물론, 맥락을 잃지 않고 중첩 배열과 하위 도큐먼트 안으로 들어갈 수 있습니다.

## 보안 & 개인정보

**데이터는 로컬에만 머뭅니다.** VisuaLeaf는 사용자의 컴퓨터에서 데이터베이스로 직접 연결합니다. 저희는 사용자의 데이터를 보거나, 저장하거나, 중계하지 않습니다.

- **직접 연결**: localhost, MongoDB Atlas, 관리형 클라우드 데이터베이스, 자체 호스팅 서버 모두 지원
- **SSH 터널링과 SSL**: 배스천 호스트를 거치거나 클라우드 인스턴스로 향하는 안전한 연결
- **오프라인 사용 가능**: 활성화 후에는 완전히 오프라인으로 동작
- **로컬 자격 증명 저장**: 연결 정보는 사용자의 컴퓨터에서 암호화되어 저장
- **쿼리 텔레메트리 없음**: 무엇을 쿼리하고 어떤 데이터에 접근하는지 추적하지 않음
