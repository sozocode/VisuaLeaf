## VisuaLeaf क्या है?

VisuaLeaf developers, DBAs और data teams के लिए एक visual **database workspace** है। इसकी शुरुआत एक MongoDB GUI के रूप में हुई थी और अब यह एक **SQL client** के रूप में भी उतना ही अच्छा काम करता है: MongoDB, PostgreSQL, MySQL, MariaDB, SQL Server, Oracle, SQLite, ClickHouse, Redis और अन्य databases से connect करें, और हर एक पर वही visual workflow इस्तेमाल करें।

Point-and-click से query बनाएँ, अपनी foreign keys से या MongoDB में असल में store किए गए data से ER diagram बनाएँ, tables और documents को inline edit करें, slow queries को profile करें, databases के बीच data move करें, dashboards बनाएँ, और AI से अपने असली schema के आधार पर queries draft करवाएँ। सब कुछ locally चलता है और सीधे आपके databases से connect होता है।

### Teams VisuaLeaf क्यों चुनती हैं

- **MongoDB और SQL के लिए एक ही app**: 36 databases, document, relational, key-value और analytics, एक ही workspace में।
- **सभी SQL features मुफ़्त हैं** Community Edition में।
- **दोनों दुनियाओं के लिए visual query builder**: SQL में foreign keys से suggest किए गए JOINs, MongoDB में AND/OR groups वाले filters।
- **ER diagram और schema visualization**: SQL foreign keys से generate या MongoDB collections से infer किए गए, और आप किसी design को असली tables या collections में materialize भी कर सकते हैं।
- **SQL editor और MongoDB shell**: syntax highlighting, autocomplete, history, और results grid, tree या JSON के रूप में।
- **Drag-and-drop aggregation pipeline designer**, हर stage पर preview के साथ।
- **AI assistant** जो सादी अंग्रेज़ी से queries, aggregations और charts लिखता है और query plans समझाता है।
- **Built-in MCP server**: Claude, Cursor और अन्य AI tools को अपने databases से connect करें।
- **असली data पर तेज़**: 50,000 documents सेकंडों में खुल जाते हैं, और MongoDB की 16 MB limit वाले documents भी आराम से handle होते हैं।
- **आपका data local रहता है**: direct connections, कोई proxy नहीं, आपकी queries पर कोई telemetry नहीं।

## Security और Privacy

**आपका data local रहता है।** VisuaLeaf आपकी machine से सीधे आपके databases से connect होता है। हम आपका data कभी नहीं देखते, store करते या proxy करते।

- **Direct connections**: localhost, MongoDB Atlas, managed cloud databases, या कोई भी self-hosted server
- **SSH tunneling और SSL**: bastion hosts के ज़रिए और cloud instances तक secure connections
- **Offline-capable**: activation के बाद पूरी तरह offline काम करता है
- **Local credential storage**: connection details आपकी machine पर encrypted रहती हैं
- **कोई query telemetry नहीं**: हम track नहीं करते कि आप क्या query करते हैं या किस data को access करते हैं
